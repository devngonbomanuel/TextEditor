# TextEditor
Um programa em console application para abrir, criar e salvar arquivos de texto.

## 🚀 Funcionalidades
- Menu interativo
- Abrir arquivo de texto passando o caminho de origem
- Criar arquivo e inserir conteúdo em texto
- Salvar arquivo de texto passando o caminho de destino

## 🛠️ Tecnologias Utilizadas
- C#
- .NET 8 SDK
